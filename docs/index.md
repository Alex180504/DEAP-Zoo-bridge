# deap_pettingzoo

`deap_pettingzoo` (**DEAP-bridge**) lets
evolutionary algorithms drive
[PettingZoo / MPE2](https://pettingzoo.farama.org) multi-agent environments, and
benchmarks them head-to-head against MARL learners (MADDPG / MATD3 / IPPO / GroupedIPPO) behind one unified API.
